# Design Brief — Lana Flowers (Telegram Mini App, C2C marketplace для букетов)

> **Для дизайн-сессии Claude.** Это самодостаточный бриф: всё необходимое для создания макетов в нём, контекст не нужен.

---

## 1. Продукт

**Что:** Telegram Mini App — C2C маркетплейс, где любой пользователь может выложить букет на продажу или купить чужой. Ключевая фича — **торг в стиле inDrive**: покупатель может купить по цене или предложить свою (выше/ниже), продавец принимает / отклоняет / делает встречное предложение.

**Платформа только сводит** — доставка и оплата происходят между пользователями (как Авито/OLX). Никаких эскроу, платежей внутри, курьерской логистики.

**Название:** **Lana Flowers**.

**География:** Казахстан, мульти-город. Цены в тенге (₸).

---

## 2. Аудитория

### Покупатели (большинство пользователей)
- Мужчины 22–45, ищут подарок (быстро, недорого, уникально)
- Женщины 25–40, себе или в подарок
- Контекст: мобильный, в спешке, часто "к вечеру"

### Продавцы
- Флористы-фрилансеры, домашние мастерицы
- Микро-магазины без своего сайта
- Случайные продавцы ("букет не подошёл")

**Соотношение:** ~90% покупатели / ~10% продавцы. Дизайн оптимизировать под покупателя.

---

## 3. Принципы

1. **Максимально просто.** Если можно убрать экран, шаг или поле — убрать.
2. **Знакомые паттерны.** Никаких изобретений — повторяем то, что юзеры знают по Авито/OLX/Telegram.
3. **Фото — главное.** Букет покупают глазами. Фото должны быть крупные, без визуального шума вокруг.
4. **Telegram-native.** Использовать MainButton, BackButton, тему пользователя, haptic feedback.
5. **Скорость загрузки.** Первый рендер < 1 сек. Никаких тяжёлых splash-screens.

---

## 4. Информационная архитектура

### Нижняя навигация — 3 таба, floating "островной" стиль
```
   ╭─────────────────────────────────╮
   │  ╭──────╮                        │
   │  │  🌸  │    💬         👤       │
   │  │Каталог│ Сообщения  Профиль    │
   │  ╰──────╯                        │
   ╰─────────────────────────────────╯
```
- **Pill-контейнер** с белым фоном (тёмно-серый #1A1A1A в dark), отступы от краёв экрана 16px по бокам и 12px снизу
- **Лёгкая мягкая тень** для эффекта "плавания" — это единственное место в дизайне где допустима тень (исключение из правила "без shadow")
- **Активный таб** подсвечен внутренней "таблеткой" #F5F5F5 (#2C2C2C в dark), иконка+текст чёрные жирные
- **Неактивные** — иконки и текст серые #6B6B6B (#9B9B9B в dark)
- Все табы показывают **иконку + подпись 12px** под ней
- Никаких цветных акцентов

**Поведение при скролле (smart nav как у Crypto Bot):**
- Скролл вниз → весь pill-контейнер плавно scaled to 92% (200ms ease-out), opacity → 95%. **Подписи и иконки остаются на месте**, ничего не исчезает — это деликатное визуальное "отдаление".
- Скролл вверх (даже на 1-2 свайпа) → scale обратно до 100%, opacity 100%
- Никаких градиентов/свечений сверху или вокруг контейнера — только мягкая тень снизу для эффекта "плавания"

**«Продать» — кнопка в шапке Каталога** (не FAB, не центральная "+"). Так не перекрывает фотки и остаётся очевидной.

## 5. Экраны (MVP)

### 5.1. Каталог (главная)
- **Шапка:**
  - Слева: селектор города (📍 Алматы ▾)
  - Справа: кнопка **«Продать»** (текст + иконка)
- **Чипсы категорий:** горизонтально-скроллящийся ряд под шапкой — `[Все] [Розы] [Пионы] [Полевые] [Композиции]`. Активный — чёрный, остальные — белый с серой обводкой.
- **Лента:** сетка карточек 2 в ряд
  - Вертикальное фото 4:5 (букеты высокие — нужна высота)
  - Цена крупно (₸)
  - Маленькая строка: аватар + имя продавца + рейтинг
  - Бейджи (опционально): «Новое», «Срочно»
- **Скелетон-лоадер** при загрузке
- **Empty state:** «В этом городе пока нет букетов — будь первым!» + кнопка «Продать»

### 5.2. Карточка букета
- **Свайп-галерея фото** (полная ширина)
- **Цена крупно** (заголовок)
- **Название** + описание
- **Карточка продавца:** аватар, имя, ⭐ рейтинг, кол-во сделок, кнопка «В профиль»
- **Действия снизу (sticky):**
  - Telegram **MainButton:** «Купить за 10 000 ₸»
  - Над ней две кнопки в ряд: **«Предложить цену»** и **«Написать»**

### 5.3. Модалка «Предложить цену»
- Большое поле ввода суммы
- Подсказка серым: «Цена продавца: 10 000 ₸»
- (Опц.) короткое сообщение к предложению
- Кнопка «Отправить»

### 5.4. Создать объявление (открывается из шапки Каталога)
- **Загрузка фото:** до 5, drag-to-reorder, первое = главное
- **Поле «Название»** (плейсхолдер: «Букет роз 25 шт»)
- **Поле «Цена»** (₸, числовое)
- **Селектор города**
- **Поле «Описание»** (многострочное)
- **MainButton:** «Опубликовать»

### 5.5. Сообщения (список чатов)
- Карточки переписок:
  - Аватар собеседника
  - Имя + последнее сообщение (1 строка)
  - Время + бейдж непрочитанных
  - Маркер ⚡ если есть активное предложение
- **Empty state:** «Здесь будут переписки с покупателями и продавцами»

### 5.6. Чат
- Шапка: аватар + имя собеседника + (для продавца) кнопка «Поделиться контактом»
- **Системные карточки в ленте сообщений:**
  - «Покупатель предложил **8 500 ₸**» + 3 кнопки: [Принять] [Встречно] [Отклонить]
  - «Сделка состоялась за **9 000 ₸**» (зелёная плашка)
  - «Продавец поделился контактом: @username» (с кнопкой написать в Telegram)
- Поле ввода + отправка фото
- Sticky миниатюра обсуждаемого букета сверху чата

### 5.7. Профиль (своя версия)
- Шапка: аватар (из Telegram), имя, ⭐ рейтинг, кол-во сделок
- Списком:
  - **Мои объявления** (с бейджем новых предложений)
  - **Мои покупки** (история)
  - **Город по умолчанию**
  - **Уведомления**
  - **Поддержка**
- Кнопка «Выйти» внизу

### 5.8. Профиль продавца (чужой)
- То же что свой, но без настроек
- Грид его активных объявлений
- Кнопка «Написать»

### 5.9. Мои объявления
- Список своих с превью, ценой, статусом (Активно / Продано / Снято)
- На каждом — счётчик новых предложений (бейдж)
- Тап → детали + список входящих предложений
- Каждое предложение: аватар покупателя, сумма, время, кнопки [Принять] [Встречно] [Отклонить]

## 7. Визуальный стиль

### Настроение
**Чёрно-белый минимализм в стиле Uber.** Утилитарный, безэмоциональный интерфейс, который не конкурирует с фотографиями цветов за внимание. Никаких декоративных элементов, паттернов, иллюстраций. Типографика и контраст — главные инструменты иерархии. Фотки букетов — единственный источник цвета на экране.

### Палитра
- **Чёрный:** #000000 — основной текст, кнопки primary, акценты
- **Белый:** #FFFFFF — фон в light-теме
- **Серые (нейтральные):**
  - #F5F5F5 — фоны второстепенных поверхностей, разделители
  - #EBEBEB — границы карточек, инпутов
  - #9B9B9B — вторичный текст, подсказки
  - #6B6B6B — иконки в неактивном состоянии
- **Системные (использовать минимально):** успех #00A86B, ошибка #E03E3E, варн #F2A93B
- **Тёмная тема (обязательна):**
  - Фон #000000, поверхности #1A1A1A, границы #2C2C2C
  - Текст #FFFFFF / вторичный #9B9B9B
  - Кнопки primary становятся белыми с чёрным текстом

**Никаких цветных акцентов.** Если нужна "выделенность" — используем чёрный, жирность шрифта или контраст фона.

### Типографика
Типографика в Uber-стиле — главный инструмент иерархии. Жирные крупные заголовки, спокойный body.
- Шрифт: **Inter** (бесплатная альтернатива Uber Move; поддерживает кириллицу и казахский)
- Размеры:
  - H1 (цена в карточке, ключевые числа): 32 / **700**
  - H2 (заголовки экранов): 22 / **600**
  - H3 (название букета): 18 / 600
  - Body: 16 / 400
  - Caption (метаданные, время): 13 / 400
  - Button: 16 / **600**

### Геометрия
Минимализм = небольшие скругления, чёткие края, много воздуха.
- Скругления: **8 px** карточки, **12 px** модалки, **8 px** кнопки и инпуты
- Отступы: базовая сетка 4 px (4 / 8 / 12 / 16 / 24 / 32 / 48)
- Контейнеры: 16 px горизонтальные поля у краёв экрана
- Разделители вместо теней: тонкая линия #EBEBEB / #2C2C2C, **никаких box-shadow**

### Иконки
Линейные тонкие — **Lucide** или **Phosphor** (variant: regular, не bold). 24×24 базовый размер. Цвет — чёрный или серый, никогда цветной.

### Кнопки
- **Primary:** чёрный фон, белый текст, 8 px скругление, padding 16/24
- **Secondary:** прозрачный фон, чёрный текст, 1 px чёрная граница
- **Text:** только чёрный текст, без фона и границ, для второстепенных действий
- В тёмной теме все цвета инвертируются

### Анимации
- 200–300 ms ease-out для большинства переходов
- Haptic feedback на: купить, предложить, принять, отклонить, опубликовать
- Skeleton при загрузке списков, не спиннеры
- Никаких bounce/playful эффектов — только функциональные переходы

## 8. Telegram-специфика (важно учесть)

- **MainButton** — нативная кнопка снизу. Используется на карточке (Купить), создании (Опубликовать), модалках. Текст и цвет настраиваются через SDK.
- **BackButton** — нативная стрелка ← в шапке Telegram. Заменяет жесты "свайп назад".
- **Safe areas:**
  - Сверху: ~50 px занимает шапка Telegram
  - Снизу: ~80 px занимает MainButton (когда активна)
- **themeParams** — все цвета должны адаптироваться к выбранной юзером теме Telegram (light/dark, и пользовательские темы тоже)
- **HapticFeedback** — таптилки на ключевые действия
- **CloudStorage** — для черновиков объявлений и выбранного города

---

## 9. Что НЕ делаем (out of MVP scope)

Чтобы дизайнер не тратил время:
- ❌ Платежи внутри платформы / эскроу
- ❌ Доставка от платформы / курьерская логика
- ❌ Видео в объявлениях
- ❌ Поисковая строка (на MVP хватит чипсов категорий — добавим в v2)
- ❌ Сложные фильтры (цена, размер, район) — только город + чипсы категорий
- ❌ Жалобы и модерация (на старте — ручной разбор)
- ❌ Промо / буст объявлений
- ❌ Подписки на продавцов
- ❌ Геолокация / карта
- ❌ Регистрация / логин (используем Telegram-юзера как ID через `initData`)

## 10. Deliverables

1. **Figma-файл** с макетами всех экранов из раздела 5 — в **light + dark** темах
2. **Компонентная библиотека** — все компоненты из раздела 6 с auto-layout и variants
3. **Прототип флоу 1:** «открыл → нашёл букет → предложил цену → договорился в чате»
4. **Прототип флоу 2:** «создал объявление → получил предложение → принял»
5. **Дизайн-токены** — цвета, шрифты, отступы — экспортируемые (формат: JSON через Figma Variables, либо аналог)
6. **Иконки** — экспорт в SVG
7. **Логотип** — текстовый wordmark «Lana Flowers» в минималистичном стиле (см. раздел Логотип ниже)

### Логотип
- **Wordmark** (текстовый), без иконки/символа
- Шрифт: тот же Inter, начертание 700 или 600
- Цвет: чёрный на белом / белый на чёрном
- Возможные стилистические штрихи: lowercase («lana flowers»), tracking чуть увеличенный для премиальности — на усмотрение дизайнера
- Альтернатива: один маленький минималистичный графический элемент (например, тонкая линия / точка) рядом с текстом — но не цветок, не цветочные мотивы. Утилитарно как у Uber.

## 11. Приоритеты для дизайн-сессии

Если делать по порядку:
1. Сначала **дизайн-токены** + общий стиль (1 экран — Каталог)
2. Затем **карточка букета** + модалка предложения цены — это сердце продукта
3. Затем **чат** с системными сообщениями о торге — вторая по важности механика
4. Затем **создание объявления** + Профиль + Сообщения
5. В последнюю очередь — empty states, skeleton-ы, edge cases

---

## 12. Открытые вопросы

Все ключевые решения зафиксированы. Если в процессе дизайна возникнут сомнения — действовать в духе раздела 7 (минимализм, чёрно-белый, фотки = единственный цвет).
