## 🎨 Общий контекст (style system)

```
Проектируем экраны Telegram Mini App «Lana Flowers» — C2C-маркетплейс
для покупки и продажи букетов в Казахстане. Любой пользователь может
выложить свой букет на продажу, другой может купить по цене или
предложить свою (выше/ниже), как в inDrive. Платформа только сводит,
никакой доставки и оплаты внутри.

ВИЗУАЛЬНЫЙ СТИЛЬ:
— Чёрно-белый минимализм в стиле Uber. Никаких цветных акцентов
  в интерфейсе. Цвет приходит ТОЛЬКО с фотографий букетов.
— Чистые линии, много воздуха, типографика как главный инструмент
  иерархии. Без декора, паттернов, иллюстраций, теней.
— Шрифт: Inter. Заголовки 22-32px / 600-700, основной текст 16/400,
  капшен 13/400.
— Цвета: чёрный #000, белый #FFF, серые #F5F5F5 / #EBEBEB /
  #9B9B9B / #6B6B6B. В тёмной теме — инверсия (фон чёрный,
  поверхности #1A1A1A, текст белый).
— Скругления маленькие: 8px карточки и кнопки, 12px модалки.
— Разделители — тонкие линии #EBEBEB, не тени.
— Кнопка primary: чёрный фон, белый текст, 8px радиус. Secondary:
  прозрачный фон с чёрной рамкой.
— Иконки тонкие линейные (Lucide style), 24×24, чёрные или серые.
— Фотографии букетов — вертикальные (соотношение 4:5), занимают
  всю ширину карточки, без отступов и рамок. Букеты по природе
  высокие, нужна высота чтобы помещался целиком.

ФОРМАТ:
— Mobile only, viewport ~390×844 (iPhone). Учитывать что сверху
  ~50px занимает шапка Telegram, снизу ~80px — Telegram MainButton
  если активна.
— Внизу экранов floating "островная" навигация в стиле
  Telegram Crypto Bot: pill-контейнер с белым фоном, отступы
  16px от краёв и 12px снизу, лёгкая мягкая тень. 3 таба
  (иконка + подпись 12px): Каталог (цветок), Сообщения
  (диалог), Профиль (человек). Активный таб подсвечен
  внутренней "таблеткой" #F5F5F5, его иконка и текст чёрные
  жирные. Неактивные — серые #6B6B6B. В тёмной теме контейнер
  #1A1A1A, активная таблетка #2C2C2C. Без цветных акцентов.
  Smart-поведение: при скролле вниз весь pill scaled to 92%
  и opacity 95% (подписи и иконки ОСТАЮТСЯ на месте, ничего
  не исчезает — деликатное визуальное отдаление). При скролле
  вверх scale обратно до 100% (200ms ease-out). Никаких
  градиентов/свечений вокруг контейнера.
— Все цены в тенге (₸).
— Покажи и light, и dark вариант экрана.
```

## 📱 Промпты экранов

### Экран 1 — Каталог (главная)

```
Главный экран мини-аппа Lana Flowers — лента букетов на продажу.

СВЕРХУ:
— Шапка с селектором города слева ("📍 Алматы ▾", тап = модалка
  выбора города) и кнопкой "Продать" справа (текст + иконка плюса,
  чёрная primary-кнопка маленького размера).
— Под шапкой — горизонтально-скроллящиеся чипсы категорий:
  [Все] [Розы] [Пионы] [Полевые] [Композиции]. Активный чипс —
  чёрный с белым текстом, остальные — белый фон с серой обводкой
  1px и чёрным текстом. Скругление чипсов — pill (полностью).

СЕТКА БУКЕТОВ (2 в ряд):
— Каждая карточка: вертикальное фото букета (соотношение 4:5) (полная ширина карточки,
  без отступов), под ним вертикальный блок с padding 12px:
  — Цена крупно жирно (например "12 500 ₸", 18px / 700)
  — Название букета мелко (14px / 400, серый, 1 строка с
    переносом многоточием)
  — Тонкий разделитель
  — Строка продавца: маленькая круглая аватарка 20px + имя +
    звёздочка ⭐ 4.8 (всё мелким серым 12px)

— Между карточками gap 8px.
— Снизу нав-бар на 3 таба: Каталог (активен, чёрная иконка цветка),
  Сообщения (серая иконка), Профиль (серая иконка).

Покажи 6 букетов в сетке (3 ряда), фотки реалистичные,
разнообразные (розы, пионы, полевые, монобукет, композиция).
Выведи light и dark вариант рядом.
```

### Экран 4 — Создать объявление

```
Форма создания объявления о продаже букета.

— Шапка: ← BackButton, заголовок "Новое объявление" по центру.
```

### Экран 6 — Чат с системными карточками предложений

```
Внутренний экран чата между покупателем и продавцом.

— Шапка: ← BackButton, аватар + имя собеседника по центру,
  иконка ⓘ справа.
— Под шапкой sticky-карточка обсуждаемого букета: маленькое
  фото 40×40 слева, название и цена справа.
— Лента сообщений (снизу вверх):

  1. Системная карточка СЕЛЕДКА: "Покупатель предложил 10 000 ₸"
     — белая карточка с чёрной рамкой, по центру жирным сумма,
     ниже три кнопки в ряд: [Принять] [Встречно] [Отклонить].
     "Принять" — чёрная primary, остальные — secondary.

  2. Текстовое сообщение продавца слева: серый bubble, белый
     текст внутри: "Могу за 11 000, букет очень свежий"

  3. Текст покупателя справа: чёрный bubble, белый текст:
     "Окей, беру за 11 000"

  4. Системная карточка успеха: "Сделка состоялась за 11 000 ₸"

     "Договоритесь о доставке в чате"

  5. Системная карточка контакта (если продавец поделился):
     "Продавец поделился контактом" + кнопка "Открыть @username
     в Telegram"

— Снизу инпут: серое поле ввода + иконка скрепки (фото) слева
  + иконка отправки справа.

Light и dark.
```

## 🧩 Доп. промпты для деталей

### Empty states
```
Покажи варианты пустых состояний для Lana Flowers (mobile,
чёрно-белый минимализм Uber-style):

1. Каталог пустой: иконка цветка серая 64px по центру, заголовок
   "В этом городе пока нет букетов" + кнопка primary "Продать
   первым".
2. Сообщения пустые: иконка диалога серая, "Здесь будут переписки
   с покупателями и продавцами".
3. Мои объявления пустые: иконка корзины, "У вас ещё нет
   объявлений" + кнопка "Создать первое".

По центру вертикально, отступы большие, текст серым.
```

### Loading states
```
Skeleton loaders для Lana Flowers в чёрно-белом стиле:

1. Каталог: 6 квадратов-плейсхолдеров в сетке 2×3 с лёгким
   shimmer-градиентом серых тонов #F5F5F5 → #EBEBEB → #F5F5F5.
2. Карточка букета: большой квадрат фото + полоски-плейсхолдеры
   под ним.
3. Список чатов: 5 строк с круглым плейсхолдером слева и двумя
   полосками справа.

Никаких спиннеров. Light и dark.
```

## ✅ Чеклист после генерации

Когда получишь макеты — проверь по этим критериям:
- [ ] Никаких цветов кроме чёрного/белого/серого в UI (только в фотках букетов)
- [ ] Никаких теней (`box-shadow`) — только разделители-линии
- [ ] Скругления маленькие (8px), не «пухлые»
- [ ] Шрифт Inter, типографика — главный акцент
- [ ] И light, и dark тема
- [ ] Telegram-нав снизу (3 таба) на всех основных экранах
- [ ] Telegram MainButton снизу там где есть главное действие
